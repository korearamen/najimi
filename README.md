# 麺屋 なじみ — 멘야 나지미

노원 상계동 돈코츠 라멘집 홈페이지.
**말 안 걸어도 편한 집.**

## 페이지

| 파일 | 내용 |
|---|---|
| `index.html` | 첫 화면 · 오늘 남은 그릇 · 대표 메뉴 · 영업시간 |
| `menu.html` | 메뉴판 · 대표 4종 · 추천 조합 · 토핑 |
| `gallery.html` | 갤러리 · 육수 · 면 · 그릇 · 가게 안 |
| `subscribe.html` | 소식받기 · 신청 양식 · 단골 안내 |
| `style.css` | 네 페이지 공통 디자인 |
| `reveal.js` | 스크롤 등장 효과 |

## 문서

| 파일 | 내용 |
|---|---|
| `SHOP.md` | 브랜드 원본. 사장님 인터뷰에서 나온 이야기 |
| `SHOP-운영.md` | 원가·손익 (내부용) |
| `DESIGN-BRIEF.md` | 디자이너 인계 문서 |
| `stitch_/` | Google Stitch 디자인 시안 (참고 자료) |

## 만든 방식

프레임워크 없이 정적 HTML + CSS + 바닐라 JS로만 되어 있습니다.
빌드 과정이 없어서 파일을 그대로 올리면 됩니다.

디자인은 Google Stitch의 **Modern Japanese Craft** 시스템을 가게 브랜드에 맞춰 옮긴 것입니다.
글꼴은 한글에 온글잎 콘콘체, 숫자·라틴에 EB Garamond, 일본어에 Shippori Mincho를 씁니다.

## 아직 안 된 것

- 오늘 남은 그릇 수가 `32`로 고정되어 있습니다. 사장님이 입력할 수단이 필요합니다.
- 소식받기 신청이 화면에서만 처리됩니다. 실제로 메일이 오지 않습니다.
- 갤러리 사진은 Unsplash 무료 사진으로 채운 임시 이미지입니다.

## 사진 출처

개업 후 실제 촬영본으로 교체합니다.
